# 🤖 DecodeBot AI - Rule-Based Chatbot

## 📌 Project Overview
DecodeBot AI is a rule-based chatbot developed using Python as part of the DecodeLabs AI Internship Project 1.

This chatbot responds to predefined user inputs using rule-based logic (`if-elif-else`) and runs continuously until the user exits.

The chatbot is designed to simulate basic human interaction and provide useful responses in a professional and interactive way.

---

## 🚀 Features

✅ Greeting Responses  
✅ Exit Commands  
✅ Help Menu  
✅ Current Time Feature  
✅ Current Date Feature  
✅ Motivation Messages

✅ Smart Input Variations Handling

## ▶️ How to Run the Project

### Step 1: Open terminal in project folder

### Step 2: Activate virtual environment

For Windows PowerShell:

```powershell
(Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned) ; (& ".venv\Scripts\Activate.ps1")
```

### Step 3: Run chatbot

```powershell
python chatbot.py
```
